# PicDeck 真機安裝與測試指南

這份文件教你把 PicDeck 裝到自己的 iPhone 上，並說明真機才測得到的項目。
模擬器的用法請看 [測試與Demo指南](./測試與Demo指南.md)。

> **誠實聲明**：這份指南的步驟是依這個專案的實際設定與 Xcode 27 寫的，
> 但我（撰寫這份文件的 AI 助理）手上沒有實體 iPhone，**沒有在真機上實際跑過一遍**。
> 遇到步驟與畫面不一致時，以你 Xcode 上看到的為準，並把差異回報，我再修正文件。

---

## 一、先看這個專案的事實

| 項目 | 目前的值 | 對你的意義 |
| --- | --- | --- |
| Bundle Identifier | `com.picdeck.app` | 免費帳號常會撞名，要改成自己的（見 2-2） |
| 最低系統版本 | iOS 17.0 | iPhone 要 iOS 17 以上才裝得上去 |
| 支援裝置 | 只有 iPhone（不含 iPad） | iPad 目前裝不了 |
| 簽章方式 | Automatic（自動） | 選好 Team 就行，不用手動管憑證 |
| 版本 | 0.1.0（build 1） | 每次重裝不用改 |
| 照片權限說明 | 已內建 | 第一次開會跳出授權視窗 |
| 資料存放 | App 的 Documents 資料夾（JSON） | 刪掉 App 資料就沒了；iCloud 備份會一起備份 |

**Liquid Glass（液態玻璃）只在 iOS 26 以上有。** iOS 17 到 25 的手機會看到半透明材質的替代樣式，
功能一樣，只是沒有玻璃的折射與互動動畫。想驗收 iOS 27 設計語言，手機要升到 iOS 26 或 27。

## 二、安裝到手機（Xcode 圖形介面，最簡單）

### 2-1 你需要準備

| 項目 | 說明 |
| --- | --- |
| Mac | 已裝 Xcode 27，並同意過授權條款（`sudo xcodebuild -license accept`） |
| iPhone | iOS 17 以上，建議 iOS 26 以上才看得到玻璃效果 |
| 傳輸線 | 第一次必須用線連 Mac，之後可以改無線 |
| Apple ID | 免費帳號就能裝，但有限制（見 2-6） |

### 2-2 設定簽章（只需做一次）

1. 打開 `PicDeck/PicDeck.xcodeproj`。
2. 左側最上面點藍色的 **PicDeck** 專案，中間 **TARGETS** 選 **PicDeck**，上方切到 **Signing & Capabilities**。
3. 勾選 **Automatically manage signing**。
4. **Team** 選你的 Apple ID。第一次沒有的話，先到 **Xcode → Settings → Accounts → +** 登入。
5. 如果 Xcode 說 **Bundle Identifier 已被使用**（免費帳號很常見），把
   `com.picdeck.app` 改成獨一無二的字串，例如 `com.你的英文名.picdeck`。
6. 只改 **PicDeck** 這個 Target。測試用的 `PicDeckUITests` 不用動。

> 改了 Bundle Identifier 之後，App 在手機上會被當成另一個 App，原本的資料不會帶過去。

### 2-3 打開手機的開發者模式（只需做一次）

1. 用線把 iPhone 接上 Mac，手機跳出「信任這台電腦？」點 **信任**，輸入手機密碼。
2. 手機到 **設定 → 隱私權與安全性 → 開發者模式**，打開它，依提示重新啟動。
3. 重開機後會再問一次，點 **打開**。

> 找不到「開發者模式」？先在 Xcode 對這支手機按一次執行（下一節），選項就會出現。

### 2-4 裝上去

1. Xcode 上方的裝置選單，從模擬器改選你的 **iPhone**（它會出現在清單最上面）。
2. 按 **⌘R**。
3. 第一次會失敗並顯示 **Untrusted Developer**，這是正常的。
4. 手機到 **設定 → 一般 → VPN 與裝置管理**，點你的 Apple ID，點 **信任**。
5. 回 Xcode 再按一次 **⌘R**。

裝好之後主畫面會有 PicDeck 圖示，之後不接電腦也能打開。

> Xcode 27 沒有獨立的 Simulator App，裝置與模擬器統一在 **DeviceHub**。
> 從 Xcode 選單 **Window → Devices** 開啟，或在終端機執行
> `open /Applications/Xcode.app/Contents/Applications/DeviceHub.app`。

### 2-5 改成無線安裝（設定過一次之後）

1. 手機仍接著線，打開 DeviceHub，選你的 iPhone。
2. 找到「透過網路連線」的選項並開啟（Xcode 27 的位置可能與舊版不同，以畫面為準）。
3. 拔掉線。手機與 Mac 在同一個 Wi-Fi 下，Xcode 的裝置選單仍會列出這支手機，直接 **⌘R** 即可。

### 2-6 免費帳號的限制

- 憑證 **7 天後過期**，過期就打不開，要接上 Mac 重新按 ⌘R。
- 同一個 Apple ID 同時最多裝 **3 個**自己簽章的 App。
- 不能用 TestFlight，不能給別人裝。
- 想給別人測試或長期使用，需要付費的 Apple Developer Program（99 美元／年）。

## 三、用指令安裝（不開 Xcode 介面）

適合重複安裝、寫進腳本。

```bash
cd /Library/WebServer/Documents/photo-app/PicDeck

# 1. 找到手機的 ID（UDID）
xcrun devicectl list devices

# 2. 編譯給真機（把 <UDID> 換成上一步的值）
xcodebuild -scheme PicDeck \
  -destination "id=<UDID>" \
  -configuration Debug \
  -allowProvisioningUpdates build

# 3. 安裝並啟動
APP=$(find ~/Library/Developer/Xcode/DerivedData/PicDeck-*/Build/Products \
      -name "PicDeck.app" -path "*Debug-iphoneos*" -maxdepth 4 | head -1)
xcrun devicectl device install app --device <UDID> "$APP"
xcrun devicectl device process launch --device <UDID> com.picdeck.app
```

- 第一次仍要在手機上信任開發者（見 2-4 第 4 步）。
- `-allowProvisioningUpdates` 讓 Xcode 自動處理描述檔，需要先在 Xcode 登入過 Apple ID。
- 如果你改過 Bundle Identifier，最後一行的 `com.picdeck.app` 也要跟著改。

## 四、真機測試前，請先做這三件事（重要）

PicDeck 會**真的動到你的照片**。

1. **先備份。** 用 iCloud 照片或電腦備份。刪除雖然會先進 iOS「最近刪除」（30 天內可救回），
   但建立、移出相簿、標記喜愛都是直接改系統照片。
2. **第一次先用少量照片。** 建議用一支測試用的手機，或在「整理」裡挑只有幾張的月份來試。
3. **知道哪些動作會改系統：**

| 動作 | 對系統照片的影響 |
| --- | --- |
| 下滑／點喜愛 | 直接改系統的「喜好項目」，在照片 App 立刻看得到 |
| 加到相簿、移出相簿 | 直接改系統相簿 |
| 建立相簿、資料夾 | 直接在系統照片建立 |
| 刪除相簿、資料夾 | 直接刪系統相簿，照片不會被刪 |
| 上滑／刪除 | 先進 App 的待刪清單，按「永久刪除」才會送進「最近刪除」 |
| 保留、標籤、日記、紀念日 | 只存在 App 自己的資料裡，不動系統照片 |

## 五、真機才測得到的項目（測試清單）

模擬器測不準或完全測不到，請在真機逐項確認。做完打勾。

### 5-1 拖拉與手感

- [ ] **觸覺回饋**：整理時保留、喜愛、刪除各有不同的震動；多選勾選有輕震；拖拉軸跨過一個月有輕震。（模擬器沒有震動）
- [ ] **拖拉軸**：一開始不顯示，滑動後才出現；用拇指單手構得到；拖動時年月、年份刻度與日期區間清楚。
- [ ] **大量照片**：照片超過幾千張時，拖拉軸拖動是否順、有沒有卡頓。
- [ ] **整理的手勢**：左滑保留、右滑回上一張、下滑喜愛（再滑一次移出）、上滑刪除。從卡片中間開始滑，太靠左邊會觸發 iOS 的「滑回上一頁」。
- [ ] **雙擊放大**：單擊沒有反應，雙擊才放大。

### 5-2 系統整合

- [ ] **照片權限**：第一次授權選「允許完整取用」；再用「限制取用」測一次，看畫面是否合理。
- [ ] **iCloud 照片**：開了「最佳化 iPhone 儲存空間」時，縮圖與放大是否能從雲端載入，載入中有沒有明確的狀態。
- [ ] **與照片 App 同步**：在 PicDeck 改喜愛與相簿，回照片 App 看是否一致；反過來在照片 App 改，回 PicDeck 是否更新。
- [ ] **相簿階層**：建立資料夾、在資料夾底下建相簿，到照片 App 確認位置。
- [ ] **刪除流程**：待刪清單按「永久刪除」，照片是否進「最近刪除」，能否救回。

### 5-3 視覺與無障礙

- [ ] **Liquid Glass**（iOS 26／27）：頁首按鈕、底部子分類與功能列、拖拉軸把手、愛心是否是玻璃質感，內容捲到後面時字是否還讀得清楚。
- [ ] **深色模式**：更多 → 介面設定，切換自動、淺色、深色，逐個畫面看對比與底色。
- [ ] **動態字級**：設定 → 顯示與亮度 → 文字大小，拉到最大，看有沒有字被截斷、版面爆開。
- [ ] **減少動態效果**：設定 → 輔助使用 → 動態效果，開啟後動畫是否改為直接切換。
- [ ] **旁白（VoiceOver）**：只有圖示的按鈕是否念得出名稱。
- [ ] **黑暗環境、強光下**：玻璃上的字是否仍清楚。

### 5-4 效能與穩定

- [ ] **冷啟動時間**：照片很多時開 App 要多久才看到畫面。
- [ ] **記憶體與發熱**：連續滑大量照片、開拖拉軸幾分鐘，手機是否明顯發熱。
- [ ] **背景切換**：整理到一半切到別的 App 再回來，狀態是否還在。
- [ ] **來電與通知打斷**：拖動中被打斷，回來後畫面是否正常。

### 5-5 資料保存

- [ ] **重開 App**：標籤、紀念日、日記、保留紀錄都還在。
- [ ] **重開機後**：同上。
- [ ] **刪除 App 重裝**：資料會消失（預期行為），照片本身不受影響。

## 六、常見問題

| 狀況 | 原因與處理 |
| --- | --- |
| 裝置選單裡看不到手機 | 線沒接好，或手機沒按「信任」。拔掉重接，手機解鎖再試。 |
| `Failed to register bundle identifier` | Bundle Identifier 被別人用了，改成獨一無二的（2-2 第 5 步）。 |
| `Developer Mode disabled` | 手機還沒開開發者模式（2-3）。 |
| 打開 App 立刻閃退，畫面寫 Untrusted | 沒有信任開發者，到手機的「VPN 與裝置管理」點信任。 |
| 過幾天 App 打不開 | 免費帳號 7 天到期，重新按 ⌘R 安裝。 |
| `No profiles for 'com.picdeck.app' were found` | 沒有選 Team，或還沒登入 Apple ID（2-2）。 |
| 玻璃效果看起來只是半透明 | 手機是 iOS 25 以下，這是預期的替代樣式。 |
| 照片全是空的 | 權限選了「限制取用」且沒挑照片，到 設定 → PicDeck → 照片 改成完整取用。 |
| 模擬器好好的，真機卡卡 | 真機的照片量遠大於模擬器。請回報照片張數與哪個畫面卡，我可以針對那裡優化。 |

## 七、要給別人測試時

免費帳號做不到，需要付費的 Apple Developer Program，流程是 Archive → 上傳到 App Store Connect →
用 TestFlight 邀請測試者。細節在 [測試與Demo指南](./測試與Demo指南.md) 的 2-6。
